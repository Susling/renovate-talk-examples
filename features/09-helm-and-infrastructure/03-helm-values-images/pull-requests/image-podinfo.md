## What happened and why

The `helm-values` manager read `values.yaml`. It looked for objects under a key that ends in `image`. The object under `podinfo.image` has `repository` and `tag`. So the manager made one dependency:

| Field in Renovate | Value | Comes from |
|---|---|---|
| `depName` | `ghcr.io/stefanprodan/podinfo` | `repository` |
| `currentValue` | `6.7.0` | `tag` |
| `datasource` | `docker` | Always `docker` for `helm-values` |

The `docker` datasource read the tags of `ghcr.io/stefanprodan/podinfo`. The newest tag was `6.7.1`. The registry is public, so Renovate needed no host rule.

Renovate changed only the `tag` line. `helm-values` has no lock file and runs no Helm command.

The title and the branch name contain the full image name with the registry. In the branch name, Renovate replaces `/` with `-`.

The image has the label `org.opencontainers.image.source` with the value `https://github.com/stefanprodan/podinfo`. So Renovate linked the package name and added the release notes of 6.7.1 from GitHub. An image without that label gets no link and no release notes.
