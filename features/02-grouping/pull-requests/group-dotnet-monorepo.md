## What happened and why

The three EF Core packages come from one source repository, `dotnet/efcore`. The `group:monorepos` preset, which `config:recommended` includes, has a rule named `dotnet monorepo`. That rule matches the source URL of each package. All three packages therefore go into one branch, `renovate/dotnet-monorepo`.

The packages must have the same version. `Microsoft.EntityFrameworkCore.Design` 9.0.1 next to `Microsoft.EntityFrameworkCore.SqlServer` 9.0.0 can give build errors or runtime errors. One PR for all three packages prevents that state.

All packages go to the same version, so the title ends with `to v9.0.1`. The release notes show one block, because all three packages have the same source URL. Renovate shows a block only one time per source.

`Serilog.AspNetCore` is not in the group. It comes from a different repository and gets its own PR, as in [feature 01](../../01-basic-updates/pull-requests/patch-serilog-aspnetcore.md).
