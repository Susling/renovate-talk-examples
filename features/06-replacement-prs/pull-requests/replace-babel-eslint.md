## What happened and why

`babel-eslint` 10.1.0 is the newest version, so a normal update does not exist. The npm registry marks the package as deprecated with this message: "babel-eslint is now @babel/eslint-parser. This package will no longer receive updates."

`config:recommended` extends `replacements:all`, and that preset extends `replacements:babel-eslint-to-eslint-parser`. The preset is a package rule:

```json
{
  "matchCurrentVersion": ">=7.11.0",
  "matchDatasources": ["npm"],
  "matchPackageNames": ["babel-eslint"],
  "replacementName": "@babel/eslint-parser",
  "replacementVersion": "7.11.0"
}
```

The rule matched, so Renovate added an update of the type `replacement` to the dependency. The new version is 7.11.0 and not the newest 7.26.5. The preset names the first version of the new package that replaces the old one. That is the "minimal stable replacement version" in the note.
