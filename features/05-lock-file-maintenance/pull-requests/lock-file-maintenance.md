## What happened and why

The service has one direct dependency: `axios` 1.7.9. Axios needs 3 packages, and `form-data` needs 3 more. Those 6 packages are transitive dependencies (dependencies of a dependency). They are not in `package.json`. Only `package-lock.json` records their versions.

```text
notifier
└── axios 1.7.9                  package.json: "1.7.9"
    ├── follow-redirects         axios asks for ^1.15.6
    ├── form-data                axios asks for ^4.0.0
    │   ├── asynckit             form-data asks for ^0.4.0
    │   ├── combined-stream      form-data asks for ^1.0.8
    │   └── mime-types           form-data asks for ^2.1.12
    └── proxy-from-env           axios asks for ^1.1.0
```

A developer created the lock file in April 2024. Later, a normal Renovate PR updated `axios` to 1.7.9. That update changed only the `axios` entry. If a locked transitive version still fits the range, npm keeps it. For this reason, `follow-redirects` and `form-data` stayed at their old versions.

On Monday at 03:07 UTC, the run was inside the schedule `before 4am on monday`. Renovate deleted `package-lock.json` on the branch. Then it ran `npm install --package-lock-only --no-audit --ignore-scripts`. npm chose the newest version that fits each range and wrote a new lock file:

| Package | Range | Before | After | "After" version published |
|---|---|---|---|---|
| `follow-redirects` | `^1.15.6` from `axios` | 1.15.6 | 1.15.9 | 2024-09-06 |
| `form-data` | `^4.0.0` from `axios` | 4.0.0 | 4.0.1 | 2024-10-10 |
| `asynckit`, `combined-stream`, `delayed-stream`, `mime-db`, `mime-types`, `proxy-from-env` | | no change | no change | already the newest in the range |

The PR has no release notes and no package list. Renovate does not compare the old and the new lock file in the body. The reviewer reads the diff of `package-lock.json`. In a large project, for example an Angular application, the same PR can change hundreds of lines.

The 👻 Immortal line replaces the 🔕 Ignore line. The default `recreateWhen` for lock file maintenance is `always`. If a person closes this PR without a merge, Renovate opens a new one at the next Monday schedule.
