## What happened and why

The `npm` manager read `"prettier": "3.3.3"` from `devDependencies`. The version is an exact pin (one fixed version, not a range). This is the style of the `config:js-app` preset, which pins all dependencies except peer dependencies.

Three releases came out after 3.3.3: 3.4.0, 3.4.1 and 3.4.2. Renovate skips the releases in between and proposes the newest one. The release notes list all three, so the reviewer sees everything that changed.

The update type is minor, because the middle number changed. The `npm` manager also updates `package-lock.json`. Renovate runs `npm install --package-lock-only` for that, so the lock file always matches `package.json`.

The `Change` cell links to `renovatebot.com/diffs`, which shows the file diff of the published npm package. This link exists only for npm packages.
