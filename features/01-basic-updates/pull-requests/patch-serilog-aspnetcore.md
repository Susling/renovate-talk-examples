## What happened and why

The `nuget` manager read `Version="8.0.2"` from the `PackageReference` element. The NuGet datasource listed 8.0.3 and 9.0.0 as newer versions. Renovate made two PRs from this one dependency, because `separateMajorMinor` is `true` by default:

- This PR, for the newest version inside major version 8.
- A separate PR for 9.0.0, which is a major update. Feature 04 shows how the Dependency Dashboard can hold that PR back until a person approves it.

The branch name ends in `-8.x`. Renovate makes one branch per major version. When 8.0.4 comes out, Renovate reuses the branch.

Renovate changes only the `Version` attribute. It does not run `dotnet restore`, because this project has no `packages.lock.json` file.
