## Before the PR

On 2021-11-04 at 15:30 UTC, somebody published rc 1.2.9, 1.3.9 and 2.3.9 to npmjs.org. The three versions had malware. A developer merged PR #409 "Update dependency rc to v1.2.9" before anybody saw the problem.

At 16:24 UTC, GitHub published the advisory [GHSA-g2q5-5433-rhrf](https://github.com/advisories/GHSA-g2q5-5433-rhrf). The advisory tells users of the three versions to go back to 1.2.8. npm removed the three versions from the registry.

From then on, the `main` branch did not build. `npm ci` stopped at the download of the removed version:

```text
npm error code E404
npm error 404 Not Found - GET https://registry.npmjs.org/rc/-/rc-1.2.9.tgz - Not found
npm error 404
npm error 404  The requested resource 'rc@https://registry.npmjs.org/rc/-/rc-1.2.9.tgz' could not be found or you do not have permission to access it.
```

This output came from npm 11.17.0 on 2026-11-21, with a `package-lock.json` that pins rc 1.2.9.

The registry had these versions after the removal:

## What happened and why

The `npm` manager read `"rc": "1.2.9"` from `package.json`. The npm datasource got 48 versions from npmjs.org. Version 1.2.9 was not one of them.

The package rule in the configuration sets `rollbackPrs: true` for `rc`. With that option, Renovate first looks for versions that match the current value `1.2.9`. It found none, so it made a rollback update:

1. Renovate kept the versions lower than 1.2.9: all 48 versions, from 0.0.1 to 1.2.8.
2. The current value 1.2.9 is a stable version. So Renovate kept only the stable versions. All 48 versions are stable.
3. Renovate took the highest of the remaining versions: 1.2.8.
4. Renovate wrote 1.2.8 into `package.json`.

The PR has no release notes. Renovate shows the release notes of the versions above the current version, and a rollback has none.

The update type is `rollback`. The `mergeConfidence:age-confidence-badges` preset sets the Age and Confidence columns only for `patch`, `minor` and `major`. So this table has the default columns: Package, Type, Update and Change.

The PR goes to the same version as the advisory: 1.2.8. Renovate does not read the advisory for this. It picks the highest version below the missing version, and that version is 1.2.8.
